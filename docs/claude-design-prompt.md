# Prompt for an independent Claude proposal

Provide this prompt and `docs/portfolio-brief.md` to Claude, with access to this
repository or its source files.

---

Read `docs/portfolio-brief.md` first. It contains anonymized project facts,
my actual contributions, evidence boundaries, privacy rules and feedback on
earlier designs.

Propose and implement your own version of my portfolio. I want your design
judgment, rather than a small variation on the existing composition. Use the
references to understand the clarity and discipline I like, not as templates.
Make the work easy to understand and the site personal, contemporary and
restrained. Keep the homepage concise and the technical depth in real case
studies and articles.

Use only Lowell as my public name and GitHub as my contact. Keep projects
anonymous, distinguish my proposals from contributions to existing products,
and invent no metrics or deployment claims. Demonstrations use fictional data.
Do not access professional repositories outside this portfolio to expand the
brief.

Work on a separate branch/worktree. Preserve the published version; do not
push or deploy. Keep the existing stack unless a concrete requirement justifies
a change. Implement the design, verify desktop/mobile behavior, run lint and
the static build, and provide a local preview with a short explanation of the
main design choices.
