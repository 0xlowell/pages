# Raw

Everything here is yours, as you wrote or captured it: notes after an
exhibition, a photo of a drawing, a quote, a link with two lines on why it
mattered. Any format is fine (`.md`, `.txt`, `.jpg`, `.png`, `.pdf`).

The agent reads this folder and never edits it. Name files so they sort by
date, for example `2026-11-20-expo-matisse.md`.
