# Logbook

One file per entry, named by date (`2026-11-20.md`, or `2026-11-20-expo.md`
for a second one that day). A line or a short paragraph, in Markdown. The
newest entries appear first on the home page.

    ---
    date: 2026-11-20
    ---
    Went to see an exhibition. Two ideas planted in the garden.
